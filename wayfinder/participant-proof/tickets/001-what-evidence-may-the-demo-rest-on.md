## Question

The demo has two labelled cases and a loop that will dispatch whatever the model asks for. The context the model sees already contains the case nicknames and the catalogue id.

What may the demo rest on?

A pass that quotes the model's sentence, or a pass that is an independent readback: queue numbers end on the owned fair profile with loaded delay down, provider numbers stay on baseline, and the journal's tool name matches the receipt. Whether the case nickname may remain in the context is part of this question. A nickname that says "interactive" makes the readback easier to fake.
